# Buddy Walk agent instructions

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Buddy-Walk/buddy-walk` (via the `gh` CLI); external PRs are not a triage surface.
See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root.
See `docs/agents/domain.md`.

### Team handbook

Human-facing map of the product and how we work: `docs/team/`.
Not published to GitHub Pages.
